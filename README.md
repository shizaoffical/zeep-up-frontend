# Zeep-Up

Zeep-Up was my first project in the tech field and marked the beginning of my web development journey. I originally created this frontend design in December 2022 while learning how to build and style websites.

## Project Overview

My work on this project focused only on designing and implementing the frontend user interface. It does not include backend development, database integration, authentication, or server-side functionality.

## Technologies Used

- HTML5
- CSS3
- Media Queries
- Slick Carousel
